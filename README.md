# Pinnacle Ledger – Fund & Budget Manager for Non-Profits

## Overview
Pinnacle Non-Profit is a desktop-based management system designed to streamline the financial tracking, budgeting, and reporting processes of non-profit organizations. It helps in managing funds, budgets, and various activities for non-profits in a transparent and efficient way. This system is built with PyQt5 and SQLite, providing a user-friendly interface for non-profit administrators and project managers to track and manage resources, expenses, donations, and more.

## Key Features
- **Fund Management:** Track and allocate funds from donors, grants, and partnerships across multiple projects.
- **Budget Tracking:** Create and manage budgets for various programs and activities. Monitor real-time expenses against budgeted amounts.
- **Transaction Logging:** Maintain a detailed record of all financial transactions, ensuring transparency and accountability.
- **Project and Activity Management:** Organize and track the progress of multiple projects and their associated activities.
- **User Management:** Different roles and permissions to ensure secure access control.
- **Reports and Analytics:** Generate detailed reports and visual analytics of fund utilization and project progress.
- **Multilingual Support:** Easily switch between languages for diverse user groups.

## Technologies Used
- **Frontend:** PyQt5 (Python GUI Framework)
- **Backend:** SQLite (Lightweight Database)
- **Language:** Python
